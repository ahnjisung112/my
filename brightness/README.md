# 모니터 밝기 조절기 (Windows)

화면 구석에 작은 창이 뜨고, **창 위에서 마우스 휠**을 굴리면 밝기가 바뀝니다.
꺼진 것처럼 보일 만큼(0% = 완전 검정) 어둡게 만들 수 있습니다.

- `win/` — **설치용 Windows 프로그램 (C, Python 불필요)** ← 권장
- `brightness.py` — 같은 기능의 Python 버전

## 동작 방식
| 구간 | 하는 일 |
|---|---|
| 20 ~ 100% | 모니터 자체 밝기(백라이트) 조절 — 외장 모니터는 DDC/CI, 노트북은 WMI |
| 1 ~ 20% | 모니터 밝기는 최저로 두고, 클릭이 통과하는 검은 막을 화면 전체에 덮어 더 어둡게 |
| 0% | 완전 검정 (화면이 꺼진 것처럼 보임) |

모니터가 DDC/CI를 지원하지 않거나, 트레이 메뉴에서 "모니터 밝기 직접 조절"을 끄면 0~100% 전체를 검은 막으로 조절합니다.
종료하거나 "원래 밝기로 되돌리기"를 누르면 모니터 밝기는 프로그램 시작 전 값으로 돌아갑니다.

## 조작
평소에는 **작업표시줄 트레이(해 아이콘)에서 대기**하고, 쓸 때만 macOS 제어 센터 같은 패널이 나타났다가 자동으로 사라집니다.
듀얼 모니터면 패널에 **모니터별 슬라이더**(EDID 이름 표시)가 나오고 각각 따로 조절됩니다.

- **트레이 아이콘 위에서 마우스 휠** → 바로 밝기 조절 (패널이 잠깐 표시)
- **트레이 아이콘 클릭** → 패널 열기 (바깥을 클릭하거나 잠시 그대로 두면 닫힘)
- 패널의 모니터 줄 위에서 휠 / 슬라이더 드래그 → 그 모니터만 · 트레이 아이콘 위 휠·단축키 → 모든 모니터 함께
- **Shift+휠** 1% · **Ctrl+휠** 10% · 패널 오른쪽 위 ✕ 로 닫기 (트레이에서 계속 대기)
- 트레이 우클릭: 모두 100/75/50/25/10/0%, 원래 밝기로 되돌리기, 모니터별 "밝기 직접 조절" 켜기/끄기, 자동 실행, 종료
- **전역 단축키**: `Ctrl+Alt+PageUp` 밝게 · `Ctrl+Alt+PageDown` 어둡게 · `Ctrl+Alt+Home` 100% (화면 아래 가운데 HUD)
- Windows 다크/라이트 모드를 따라 패널·트레이 아이콘 색이 바뀝니다.
- `Brightness.exe --background` 로 실행하면 패널 없이 조용히 시작합니다 (자동 실행에 사용).

## 빌드 (Linux에서 Windows용으로)
```sh
sudo apt install gcc-mingw-w64-x86-64 nsis
brightness/win/build.sh   # -> win/out/Brightness.exe, win/out/BrightnessSetup.exe
# 아이콘을 바꾸려면: cd brightness/win && python3 make_icon.py  (Pillow 필요)
```
설치 프로그램은 관리자 권한 없이 `%LOCALAPPDATA%\Programs\BrightnessControl`에 설치하고,
시작 메뉴·바탕화면 바로가기와 (선택) Windows 시작 시 자동 실행을 등록합니다.
