# 모니터 밝기 조절기 (Windows)

화면 구석에 작은 창이 뜨고, **창 위에서 마우스 휠**을 굴리면 밝기가 바뀝니다.
꺼진 것처럼 보일 만큼(0% = 완전 검정) 어둡게 만들 수 있습니다.

## 동작 방식
| 구간 | 하는 일 |
|---|---|
| 50 ~ 100% | 모니터 자체 밝기(백라이트) 조절 — 외장 모니터는 DDC/CI, 노트북은 WMI |
| 1 ~ 50% | 모니터 밝기는 최저로 두고, 클릭이 통과하는 검은 막을 화면 전체에 덮어 더 어둡게 |
| 0% | 완전 검정 (화면이 꺼진 것처럼 보임) |

- 모니터가 DDC/CI를 지원하지 않으면 0~100% 전체를 검은 막으로 조절합니다.
- 어두운 쪽은 감마 곡선으로 촘촘하게 나눠, 바닥 근처에서도 세밀하게 조절됩니다.
- 화면이 어두워지면 조절 창도 같이 흐려지고, 마우스를 올리면 선명해집니다.
- 검은 막 아래에서도 마우스 클릭·키보드 입력은 평소처럼 됩니다.

## 조작
- **마우스 휠** (창 위): 2%씩 · **Shift+휠** 1% · **Ctrl+휠** 10%
- 막대 클릭/드래그, 방향키 ↑↓
- 우클릭 메뉴: 100/75/50/25/10/0% 바로가기, 종료
- 창 드래그로 위치 이동, ✕ 또는 Esc로 종료
- **전역 단축키** (어디서든): `Ctrl+Alt+PageUp` 밝게 · `Ctrl+Alt+PageDown` 어둡게 · `Ctrl+Alt+Home` 100%로 복구

종료하면 검은 막은 사라지고, 50% 미만에서 종료한 경우 모니터 밝기는 시작 전 값으로 돌아갑니다.

## 실행
1. [Python 3](https://www.python.org/downloads/) 설치 (추가 라이브러리 필요 없음)
2. `실행.bat` 더블클릭

exe 파일이 필요하면 `exe만들기.bat`을 실행하세요 → `dist\밝기조절.exe`

## 참고
- 외장 모니터는 OSD 메뉴에서 **DDC/CI** 가 켜져 있어야 백라이트 조절이 됩니다.
- 노트북 밝기 조절은 PowerShell을 거쳐서 반영까지 약간 지연될 수 있습니다.
