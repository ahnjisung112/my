# 파일 정리 도구 (폐쇄망용 단일 HTML)

`파일정리.html` 하나로 끝나는 파일·폴더 정리 도구입니다. 설치 프로그램(.exe/.msi)이 필요 없고, 네트워크 연결도 전혀 쓰지 않습니다.

## 반입·실행

1. `파일정리.html` 파일 하나만 승인된 매체(USB, 망연계 등)로 반입합니다.
2. 사내 PC 아무 폴더에 두고 두 번 클릭하면 엣지(Edge)에서 열립니다.
3. "폴더 선택" → 정리 규칙 선택 → "미리보기 만들기" → "선택한 파일 지금 정리하기".

## 동작 방식

- **직접 모드 (기본)**: 엣지/크롬의 File System Access API를 사용합니다. 사용자가 직접 고른 폴더 안에서만 읽고 옮길 수 있고, 그 바깥은 브라우저가 접근 자체를 막습니다. 처음 한 번 "파일 수정 허용" 확인창이 뜹니다.
- **읽기 전용 모드 (대체)**: 사내 정책으로 위 API가 막혀 있으면 자동으로 전환됩니다. 폴더 목록만 읽어 미리보기를 만들고, 실제 이동은 생성된 `.bat` 스크립트를 폴더 안에 넣고 실행해서 처리합니다. 내려받기까지 막혀 있으면 "스크립트 내용 복사"로 메모장에 붙여넣어 `.bat`로 저장하면 됩니다.

## 정리 규칙

| 규칙 | 결과 예시 |
|------|-----------|
| 종류별 | `문서/`, `이미지/`, `영상/`, `음악/`, `압축/`, `도면/`, `기타/` |
| 월별 (수정일) | `2026-10/`, `2026-09/` |
| 종류별 → 월별 | `문서/2026-10/` |

- 파일명 앞에 수정일 붙이기 옵션 (`20261023_보고서.docx`)
- 제외 확장자 지정
- 같은 이름이 이미 있으면 `이름 (1).ext` 식으로 번호를 붙입니다. 덮어쓰기는 하지 않습니다.
- 직접 모드에서는 "되돌리기"로 방금 정리한 파일을 원래 자리로 복구할 수 있습니다.
- `Thumbs.db`, `desktop.ini`, `~$`로 시작하는 임시 파일, 숨김 파일(`.`으로 시작)은 건드리지 않습니다.

## 제한 사항

- 윈도우 `C:\Windows`, `Program Files` 같은 시스템 폴더는 브라우저가 선택을 거부합니다.
- 같은 폴더 안의 이름 변경은 수정일이 유지됩니다. 다른 폴더로 옮길 때 브라우저가 "이동"을 지원하지 않으면 "복사 후 원본 삭제"로 처리되며, 이 경우 파일의 수정일이 복사 시점으로 바뀝니다. 수정일이 중요한 자료는 `.bat` 방식(윈도우 `move` 명령)을 쓰면 그대로 유지됩니다.
- 되돌리기 후 비어 있는 분류 폴더는 자동으로 지우지 않습니다.
- 생성된 `.bat`는 UTF-8로 저장되며 첫 줄에서 `chcp 65001`을 실행합니다. 윈도우 10 이상에서 한글 파일명이 정상 처리됩니다.

# 폴더 정리 어시스턴트 (`정리어시스턴트.html`)

파일을 옮기거나 지우지 않고 **읽기만** 해서 "어떻게 정리해야 하는지" 알려주는 진단 도구입니다. 권한 확인창이 없고, 폴더 쓰기가 정책으로 막힌 PC에서도 그대로 동작합니다.

## 사용

1. `정리어시스턴트.html`을 두 번 클릭해 엣지에서 엽니다.
2. "폴더 선택"으로 진단할 폴더를 고릅니다. 브라우저가 "업로드하시겠습니까?"라고 물으면 "업로드"를 누르세요. 어디에도 보내지 않고 이 창 안에서 목록만 읽습니다.
3. 진단 결과를 "먼저 할 것 → 다음에 할 것 → 여유 있을 때" 순서로 처리합니다.
4. "체크리스트(.txt) 저장" 또는 "인쇄 / PDF로 저장"으로 결과를 남깁니다.

## 진단 항목

| 구분 | 항목 |
|------|------|
| 먼저 할 것 | 최상위에 흩어진 파일, 파일이 과다한 폴더 |
| 다음에 할 것 | 오래 손대지 않은 파일(연도별 집계), 중복 파일(이름+크기 동일), "최종·사본·v2" 꼬리표 버전 묶음, 6단계 이상 깊은 폴더, 이름이 거의 같은 형제 폴더 |
| 여유 있을 때 | 임시·찌꺼기 파일, 파일 1~2개뿐인 폴더, 날짜 표기 방식 혼재, 종류가 섞인 폴더, 100MB 이상 파일, 실행·설치 파일 |

항목마다 "왜 문제인지"와 "무엇을 하면 되는지"를 적고, 해당 파일 목록을 펼쳐 볼 수 있습니다. 자료의 연도 분포에 따라 "종류별" 또는 "진행중 / 보관(연도별)" 권장 폴더 구조를 그려 줍니다.

실제 이동은 `파일정리.html`로 하거나, 체크리스트를 보며 탐색기에서 직접 정리하면 됩니다.

# 실시간 정리 추천 (`실시간정리.html`)

폴더를 한 번 고르면 페이지가 4초마다 그 폴더를 다시 읽어, 파일마다 "이름을 이렇게 바꾸세요 / 이 폴더로 옮기세요 / 이 둘은 합치세요"를 카드로 띄웁니다. 카드마다 적용·건너뛰기 버튼이 있고, 새로 생긴 파일은 "새로 감지" 표시가 붙습니다.

## 사용

1. `실시간정리.html`을 엣지에서 열고 "폴더 선택"을 누르거나, 탐색기에서 폴더를 창으로 끌어다 놓습니다.
2. 창을 켜 둔 채로 평소처럼 일합니다. 그 폴더에 파일이 생기면 몇 초 안에 추천이 뜹니다.
3. 추천 카드의 "적용"을 누르거나 "보이는 추천 모두 적용"으로 한 번에 처리합니다. "방금 적용한 것 되돌리기"로 복구할 수 있습니다.

## 추천 종류

| 종류 | 내용 |
|------|------|
| 이름 변경 | 날짜 형식 통일(2024.05.13 → 2024-05-13), "- 복사본", "(1)" 꼬리표 제거, 앞뒤·연속 공백 정리, 선택 시 수정일 접두어 |
| 이동 | 최상위에 흩어진 파일을 종류별·월별 폴더로, 오래 손대지 않은 파일은 `보관/연도/`로 |
| 합치기 | 이름·크기가 같은 중복은 하나만 남기고 나머지를 `중복/`으로, "최종·사본" 버전 묶음은 최신본만 남기고 나머지를 `이전버전/`으로, 띄어쓰기만 다른 형제 폴더는 하나로 |

- 바로 지우지 않습니다. 중복과 옛 버전은 `중복/`, `이전버전/` 폴더에 모아 두므로 확인 후 직접 지우면 됩니다.
- 하위 폴더까지 읽을 때도 이동 추천은 최상위 파일에만 합니다. 이미 만들어 둔 폴더 구조는 건드리지 않습니다.

## 한계

- 브라우저는 탐색기 창이 열리는 것을 감지하거나 다른 폴더를 몰래 볼 수 없습니다. 고른 폴더 안에서만 동작합니다. 다른 폴더를 보려면 다시 고르거나 끌어다 놓으세요.
- 파일만 끌어오면 추천은 보여 주지만 적용은 못 합니다. 적용하려면 그 파일이 들어 있는 폴더를 골라야 합니다.
- 폴더 간 이동이 "복사 후 삭제"로 처리되면 수정일이 바뀝니다(위 제한 사항 참고).
- 페이지를 닫으면 감시도 끝납니다. 다시 열면 폴더를 다시 골라야 합니다.
